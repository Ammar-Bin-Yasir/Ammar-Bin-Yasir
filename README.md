### Featured projects

**🎮 [Connect 4 with AI Bot](https://github.com/Ammar-Bin-Yasir/Connect-4-Game-with-AI-Bot)**
A Connect 4 game with an AI opponent powered by minimax and alpha-beta pruning — a from-scratch game-tree search with a hand-tuned positional evaluation function, built with Python and Pygame.

**📺 [Anime Tracker](https://github.com/Ammar-Bin-Yasir/Anime-Tracker-Flask-Application)**
A full-stack Flask web app for tracking anime watchlists, with a content-based recommendation engine built on TF-IDF and cosine similarity — plus auth, search, filtering, and a real SQLite-backed catalog of ~20,000 titles.
